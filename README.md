## 简介

本项项目是自媒体GEO系统+新媒体SEO矩阵系统，GEO支持网易、搜狐、百家号等、SEO矩阵目前支持抖音、快手、视频号、小红书平台多账号管理及分发，如下是整个工程模块
![image](https://github.com/juneSir1/cxlaike-module-cxlaike/assets/22173263/0fc5db65-63b2-4967-8f2a-bf7e615af5ce)

## 性能
1. 本项目使用java8+vue2.0 语言开发，SaaS平台化商户管理；
2. 多平台账号托管客户端使用 Electron+vue3.0，
3. 上传视频、图片等素材做了应用隔离，100M视频5s内完成；
4. 秒级计算混剪视频不重复组合，分钟级生成上千条不重复视频；

## 项目支持的功能
一、GEO模块：
* 1、Ai诊断品牌（企业）在大模型的收录报告生成；
* 2、GEO AI内容生成（底层接入Deepseek+Chatgpt）；
* 3、GEO文章多平台发布，支持定时发布；
* 4、GEO发布后的AI搜录情况统计;
* 5、核心词分析、AI平台分析、竞品分析、引用来源数据分析；

二、新媒体SEO矩阵：
* 1、SaaS平台：多商户管理，商户充值续费；
* 2、多平台：抖音、快手、视频号、小红书、百家号、头条、网易号、知乎、搜狐、CSDN平台多账号授权管理自动发布，及每个账号支持独立代理IP隔离；
* 3、智能混剪：自有视频组合算法，短视频批量化混剪，分钟级1000条不重复视频；
* 4、素材管理：视频、图片、音频素材快速上传和管理；
* 5、AI文案：接入Deepseek+ChatGPT3.5，多种脚本模型匹配，自动生成；
* 6、智能分析：智能分析视频表现数据、账号表现数据及综合指标分析查看；
* 7、互动线索：私信、评论自动同步、回复功能；
* 8、多门店：多门店位置等信息管理；
* 9、财务管理：商户自主续费、充值；
